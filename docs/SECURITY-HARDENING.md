## 資源政策及部署後追蹤

- 每分鐘每 IP：auth 120，其餘分類（一般讀取、寫入、WebSocket 握手）240。每分鐘整體：auth 300，其餘分類 1200；佇列最多 128，滿載回 503／Retry-After，頻率或連線配額回 429／Retry-After。
- 速率桶最多 4096，逾期清除；DO 重啟會重設記憶體頻率桶，不能取代 Cloudflare WAF／邊緣配額。固定 SQL 登入失敗計數仍持久化。每 IP 配額考慮校內共用出口，部署前應依實際規模在隔離環境調整。
- 尚未代為建立外部 Logpush／告警規則、MFA、Access、WAF 或容量監控。建議對 `loginFailed`、`accessDenied`、`rateLimited`、`requestError` 建立告警；日誌大量受限時需在邊緣記錄彙總指標。這些是平台維運待辦，不表示已完成帳號層級設定。
- CSP 已檢查資產來源與回應標頭；未進行互動式瀏覽器／Google Fonts 外連的完整視覺回歸。不得宣稱正式環境已修復。

## 可重跑驗證

`npm ci --ignore-scripts` → `npx tsc --noEmit` → `npm run test:security` → `npm run build` → `npm audit`

測試只使用記憶體 Miniflare 及每次產生的測試憑證，不連正式環境。涵蓋公開／授權 REST、WebSocket 快照與更新的隱私、教師密碼政策、型別／邊界值驗證、重新驗證拒絕／成功、401／403 稽核及限流。為避免等待，僅測試 bundle 的近期驗證改為 1 秒、每 IP WebSocket 改為 8；正式原始碼仍為 5 分鐘及 128。未做正式壓測、攻擊 PoC、瀏覽器視覺驗證或外部平台設定變更。
