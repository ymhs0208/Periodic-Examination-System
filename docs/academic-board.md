# 教務處總覽看板

- 本機入口：`http://localhost:3000/board/academic`。
- 已登入教務管理員：頁首「教務處看板」或帳號選單 → 教務處看板。
- 直接開啟網址但未登入：先出現教務管理員登入；監考老師帳號不能查看此看板。
- 執行 `npm run dev`（建置後啟動本機 Worker）；若本機服務已開著，先執行 `npm run build`，重新整理。

## 畫面

1. 學校／考試名稱、台北時間時鐘、返回管理中心、全螢幕投影。
2. 即時連線與資料接收時間；離線／同步中斷時，頂部醒目警告舊資料並可重新連線。
3. 大字統計：全校考場、已回報、已知實到、已知缺席、未回報與待確認人數。
4. 優先關注摘要及今日緊急／未處理通報數。
5. 全校卡片：班級、節次、科目、時間、應到／實到／缺席與狀態。
6. 多考場投影時按可用螢幕大小分頁；每 12 秒輪播，可暫停／手動換頁，總計與優先關注一直顯示。不投影時直接列出全部考場，不需先選班級。

## 定義與限制

- 每班依「進行中 → 今日下一節 → 今日最後一節」顯示，不混用上節點名。節次為各班今日考程的排序。
- 未開始且未回報不算異常；已開始／已結束卻未回報才計入「未回報」。無今日考程的班級仍列出，但不納入出缺席。
- 未回報的實到／缺席顯示 `—`，不能解讀為零或全勤。
- 缺席偏高：已回報且缺席 ≥3 人，或缺席率 ≥10%。
- 排序：今日緊急通報 → 未回報 → 缺席偏高 → 今日其他未處理通報 → 其他考場。
- 通報沒有節次欄位，因此摘要明確標「今日」，只統計今日且未解決者，不投影通報內容。
- **連線狀態指此看板與伺服器的連線**。後端沒有各考場裝置心跳，不能宣稱能偵測個別考場斷線，也不以點名時間推測斷線。
- 即使管理員拿到完整資料，此看板仍不顯示學生姓名、座號、缺席原因、通報內容、教師帳號。沿用既有 API／WebSocket，未新增公開端點。
- 瀏覽器未允許原生全螢幕時，退回視窗投影模式並提示；Esc 或退出按鈕可返回。
- 尊重減少動態效果偏好：預設暫停輪播，可手動開始。
- `/attendance` 與 `/attendance/school` 仍為操作台，沒有加回全螢幕；單班黑板、管理中心表格預設不變。

## 驗證

- `npx tsc --noEmit`
- `npm run build`
- `node tests/academic-board.mjs`：12 項資料邏輯、投影遮罩與登入／入口測試（記憶體測資，無正式環境操作）。
- `node tests/ux-regressions.mjs`
- `npm run test:security`

上牆前仍應在實際投影解析度確認原生全螢幕、退出、換頁與長班名顯示。此改動沒有部署、提交或推送。
